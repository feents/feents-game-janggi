# FEENTS 장기

React + Vite와 Fairy-Stockfish WASM으로 만든 브라우저 AI 장기입니다. 착수·AI 탐색·규칙 판정은 모두 브라우저에서 실행하며, 대국 서버나 외부 AI API가 필요하지 않습니다.

## 실행과 배포

Node.js 22.12 이상에서 실행합니다. 엔진 바이너리는 저장소에 포함되어 있어 일반 실행·배포 때 Emscripten을 설치할 필요가 없습니다.

```sh
npm ci
npm run dev
```

기본 주소는 `http://127.0.0.1:5173`입니다. 로컬 개발과 미리보기 서버는 COOP·COEP 헤더를 함께 제공합니다.

```sh
npm test
npm run build
npm run preview
```

`dist/`를 nginx 웹 루트에 복사하고 `deploy/nginx.conf`를 적용합니다. 운영 주소는 **HTTPS**로 제공해야 합니다. 예시 nginx 설정은 TLS를 종료하는 프록시 뒤에서 사용하는 HTTP 정적 서버 블록이므로, 공개 서비스에서는 앞단 HTTPS 또는 nginx TLS 설정을 추가합니다. 문서와 Worker 응답에 `Cross-Origin-Opener-Policy: same-origin`, `Cross-Origin-Embedder-Policy: require-corp`를 유지하고 `.wasm`은 `application/wasm`으로 제공합니다. 엔진 요청을 HTML로 fallback하지 않습니다.

GitHub Actions는 `scripts/deploy.sh`에서 SSH와 `rsync --delete --delete-delay --delay-updates`로 `dist/`의 내용을 동기화합니다. 빌드에서 사라진 파일과 이전 해시 번들은 전송 후 `DEPLOY_PATH`에서 삭제됩니다. 이 경로는 기존에 존재하고 쓰기 가능한 장기 앱 전용 폴더여야 하며, 내부 파일이 빌드 내용과 같도록 정리됩니다. 서버에는 rsync가 설치되어 있어야 하고, Actions 실행 환경에는 workflow가 rsync와 OpenSSH를 설치합니다. 기존 `SERVER_HOST`, `SERVER_USER`, `SSH_PRIVATE_KEY`, `DEPLOY_PATH` Secrets와 선택적인 `SERVER_PORT`(기본 22)를 사용합니다.

WASM SIMD, Worker, SharedArrayBuffer를 지원하는 최신 브라우저가 필요합니다. 로컬 localhost·127.0.0.1은 HTTP로 테스트할 수 있습니다. 공유 메모리를 제공하지 않는 일부 앱 내장 브라우저에서는 일반 브라우저로 열도록 안내합니다. 현재 실제 UI 검증 브라우저는 Chrome이며 Safari·Firefox 실기기 검증은 별도입니다.

## 대국 기능

데스크톱에서는 무르기·한수쉼·새 게임과 차례 안내를 우측 기보 위에 배치해 장기판이 화면 높이를 더 활용합니다. 좁은 화면에서는 장기판 아래에 조작 영역과 기보가 이어집니다.

기본 설정은 5분·빅장 끔·기물승 켬·반복수 켬입니다. 양쪽 상차림 선택 순서는 상마상마 → 마상마상 → 마상상마 → 상마마상이며, 처음 선택된 상차림은 초나라 상마상마·한나라 마상마상입니다. 내 진영을 바꾸면 각 나라의 상차림 선택값을 유지한 채 사용자와 AI의 역할을 교체합니다.

- 사용자는 초·한을 선택하며 항상 아래에 표시됩니다. 초가 먼저 두므로 한을 선택하면 AI가 선공합니다. 양쪽 상차림은 각각 4종입니다.
- 양쪽 플레이어 정보 아래에 각자 잡은 상대 말을 모읍니다. 말은 ID 순서로 SVG 요소를 유지하고 Web Animations API로 이전 위치부터 약 180ms 동안 이동합니다. 복기를 빠르게 넘기면 진행 중인 화면 위치부터 새 목적지로 이어집니다. 잡힌 말은 약 240ms 동안 해당 회수영역으로 이동합니다. 운영체제의 동작 줄이기 설정에서는 애니메이션을 생략합니다.
- 말을 클릭하거나 탭하면 합법 목적지를 표시합니다. 방향키와 Enter·Space로도 선택·착수할 수 있습니다. 최근 수, 장군, 말 잡기와 기물 점수를 즉시 표시합니다.
- AI 18급~9단은 엔진 Skill Level과 수당 생각 시간을 함께 조절하는 **게임 내 상대 난이도**입니다. 공인 기력이나 보장된 단수를 뜻하지 않습니다. 생각 시간은 대략 0.18~3.5초이며 기기 성능과 남은 시간의 영향을 받습니다.
- 실제 기보, 한수쉼, 기권 후 새 게임, 외통·무승부·시간패·기물승의 결과를 제공합니다. 종료 시 중앙 결과 모달에서 승리·패배·무승부와 사유, 최종 점수를 명확히 보여주고 복기 또는 새 게임으로 이어집니다.
- 기본 시간은 0~60분, 초읽기는 10~60초·1~5회입니다. 기본 시간이 0이면 즉시 초읽기를 시작합니다. 현재 초읽기 시간이 끝날 때 회차를 소모하고, 합법 착수 후 남은 회차의 시간을 초기화합니다. 탭이 숨겨져 타이머 호출이 늦어져도 실제 경과 시간을 정산합니다.
- 무르기는 사용자 자신의 직전 수를 두기 전으로 돌아갑니다. AI 탐색 중이면 1수, 응수 후면 2수를 되돌리고 양쪽 시간과 반복 이력도 복원합니다. 한을 선택했을 때 AI의 첫 수만 있는 상태는 무를 수 없습니다. 0~10회 또는 무제한이며 무르기 사용 횟수는 복원하지 않습니다.
- 엔진 오류 시 시간을 멈추고 다시 시도로 같은 기보를 복원합니다. 무르기·새 게임·기권·종국·페이지 이탈 시 기존 Worker와 탐색을 종료하고 늦은 응답을 버립니다.

설정과 대국은 현재 페이지 메모리에만 유지됩니다. 새로고침은 새 게임으로 돌아갑니다. 시작 전 블러, FEENTS 헤더, 나무 장기판, 초 초서체·한 해서체, 로컬 폰트 로딩 후 렌더링을 유지합니다.

## 대국 종료와 복기

종료 모달의 `복기하기`를 누르면 처음 배치부터 돌아볼 수 있습니다. 처음·이전·다음·마지막 수 버튼, 수 선택 슬라이더, 기보의 수 선택을 지원합니다. `자동 재생`은 0.9초 간격으로 한 수씩 진행하며 마지막 수에서 멈춥니다. 모바일에서는 복기 조작을 화면 하단에 고정해 판을 보면서 사용할 수 있습니다.

복기는 착수별 판·회수한 말·점수·착수 직후 시계를 함께 보여줍니다. 한수쉼도 한 수로 기록하며 장군·최근 수 표시도 해당 국면을 따릅니다. 복기 중에는 착수나 AI 탐색이 실행되지 않습니다. 종료 직전의 시간 경과는 최종 결과 화면에서, 각 수의 시계는 복기에서 확인합니다. `복기 종료`는 실제 최종 판으로 돌아갑니다.

기권도 결과 모달을 먼저 표시합니다. `새 게임 시작`에서 설정을 취소하면 종료된 대국의 판과 복기 이력을 유지하고, 실제로 시작하기를 눌렀을 때 이전 대국의 이력과 회수영역을 비웁니다. 새로고침 후 저장이나 별도 파일로 기보 내보내기는 제공하지 않습니다.

## 규칙 옵션

| 옵션 | 적용 방식 |
| --- | --- |
| 빅장 켬 | 궁이 마주 보면 상대는 대면을 해소하거나 한수쉼으로 무승부를 수용합니다. |
| 빅장 끔 | 궁의 대면 자체는 장군이나 종료 사유가 아니며 유지할 수 있습니다. |
| 기물승 켬 | 어느 한쪽의 **덤 제외 기물 점수**가 10점 미만이면 총점으로 승패를 가립니다. 한의 덤 1.5점은 비교에 포함합니다. 10점은 계속, 9점은 판정 대상입니다. 외통을 우선 판정합니다. |
| 반복수 켬 | 말 배치와 차례가 같은 국면이 세 번째 발생하는 수를 금지합니다. 초기 배치도 첫 번째로 셉니다. |
| 반복수 끔 | 반복만으로 무승부나 금지 수가 생기지 않습니다. |

양쪽이 연속으로 한수쉼하면 무승부입니다. 장군 중에는 한수쉼할 수 없지만 빅장 수용은 엔진의 빅장 규칙을 따릅니다. 연속 한수쉼·빅장 수용으로 즉시 끝나는 수는 반복 제한보다 종국 판정을 우선합니다. 불필요한 기본 엔진의 50수·자동 반복·기물 부족 무승부는 이 게임 변형에서 사용하지 않습니다.

차 13점, 포 7점, 마 5점, 상·사 3점, 졸·병 2점이며 궁은 0점입니다. 초는 72점, 한은 덤 포함 73.5점으로 시작합니다. 기물승 옵션과 관계없이 양쪽 점수와 한의 덤 내역을 보여줍니다.

## 엔진 구조와 재빌드

`public/engine/ffish.js·wasm`은 규칙 판정용, `stockfish.js·wasm`은 AI 탐색용입니다. 같은 소스·커스텀 규칙 패치를 적용한 8개 변형을 사용하고, AI에는 초기 FEN과 전체 기보를 전달합니다. 반환한 수는 규칙 엔진의 합법 수 목록으로 다시 확인합니다. 규칙 Worker와 AI Worker를 분리해 탐색 중에도 UI가 응답합니다.

AI는 Classical 평가를 사용합니다(`Use NNUE=false`). 추가 NNUE 모델 다운로드 없이 실행합니다. 탐색 Threads는 1, Hash는 16 MiB이며 pthread 런타임 때문에 공유 메모리와 격리 헤더가 필요합니다. 선언한 WASM 초기 메모리는 AI 128 MiB, 규칙 32 MiB이며 실제 전체 메모리 소비와 같지는 않습니다.

고정 upstream 커밋, Emscripten 버전, 파일 크기·SHA-256은 `engine/manifest.json`에 있습니다. 규칙 변경은 `engine/feents-rules.patch`, 최신 Emscripten의 메시지·출력 연결 보정은 `scripts/patch-engine-glue.mjs`에 보관합니다.

Emscripten 3.1.74 환경을 활성화한 뒤 다음 명령으로 두 엔진을 함께 재빌드할 수 있습니다. GitHub 소스 다운로드를 위한 네트워크와 make·patch·curl·Node.js가 필요합니다.

```sh
source /path/to/emsdk/emsdk_env.sh
bash scripts/build-engine.sh
npm test
npm run build
```

빌드 스크립트는 임시 디렉터리에 고정 소스를 내려받아 패치하고, 두 엔진의 빌드가 모두 성공했을 때 자산과 manifest를 교체합니다. 일반 앱 빌드에서는 이 절차를 실행하지 않습니다.

## 검증 범위

`npm test`는 총 89개 테스트로 기존 상차림·점수 검증과 실제 WASM 규칙·AI 테스트, 시간·대국 상태·터치 영역·배포 테스트를 실행합니다. 배포 테스트에는 Bash, OpenSSH, rsync가 필요합니다. 주요 검증은 다음과 같습니다.

- 진영·상차림·규칙의 256개 초기 조합, 좌표/FEN 왕복, 모든 기물의 이동·막힘·잡기·궁성 제약.
- 빅장 해소/수용/끔, 연속 한수쉼, 기물 10↔9점 경계와 덤, 외통 우선, 반복 금지와 이력 복원.
- 27개 난이도 및 8개 규칙의 실제 AI 합법 착수, 반복 직전 탐색, 초기 배치부터 종료까지 AI 대국.
- 실제 로컬 rsync 갱신·삭제, 잘못된 배포 설정·불완전한 빌드·심볼릭 링크 차단, SSH·전송 실패 처리와 임시 키 정리. 배포 테스트는 임시 폴더만 사용하고 운영 서버에 접속하지 않습니다.
- 초읽기 경계·지연 정산, 선후공, 무르기 0/유한/무제한, 탐색 취소·기권·새 게임의 늦은 응답, 오류 복구, 페이지 이탈.
- 엔진 초기화 지연·실패·재시도·이전 대국의 늦은 응답, 준비 시간 제외와 준비 직후 첫 착수. 준비 중에는 메인 영역의 블러와 로딩 표시를 유지합니다.
- 무르기 복원 중에는 로딩 모달 없이 판을 유지하고 착수·중복 무르기와 시계를 잠시 멈춥니다. 복원 실패·페이지 이탈·새 대국 시작 후 이전 복원 응답 무시도 검증합니다.
- 90개 터치 영역의 빈틈·겹침 없는 판 내부 분할, 모서리까지 가장 가까운 칸에 대응하는지와 초·한 방향 변환. 녹색 이동 점 크기는 유지합니다.

브라우저에서는 초·한 실제 착수와 AI 응수, AI 탐색 중/응수 후 무르기, 키보드 착수, 모바일 390px 배치, 한수쉼·기권·새 게임, 실제 초읽기 시간 초과를 확인합니다. 테스트용으로 직접 시작한 개발·미리보기 서버는 확인 후 종료합니다.

## 디자인과 자산

`feents-design` 스킬 및 [맛집 지도](https://taste.feents.com), [FIFA](https://fifa.feents.com)의 공통 헤더를 참고했습니다. Pretendard Variable과 JetBrains Mono는 외부 CDN 호출 없이 `public/fonts/`에서 제공합니다. 폰트 라이선스는 같은 폴더의 `*-LICENSE.txt`에 있습니다.

장기 진영·말·상차림은 [PyChess 장기 설명](https://www.pychess.org/variants/janggi)을 참고했습니다. 나무 장기판과 팔각형 말 몸체는 프로젝트에서 직접 작성한 SVG입니다.

말의 글자 도안은 [Kadagaden의 chess-pieces](https://github.com/Kadagaden/chess-pieces/tree/b035b0cc6a68e9fb99c872c8fe073c3ae3eba8a0/janggi_kakao_janggi_style_white)를 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)으로 사용합니다. 원본 14개 말에서 글자 획만 추출하고, 효과를 제거한 뒤 윤곽에 맞는 viewBox·크기·색상을 적용했습니다. 도안 데이터는 `src/assets/janggi-glyphs.js`, 저작자와 변경 내역 및 라이선스 전문은 `public/licenses/`에 있으며 빌드에도 포함됩니다. 실행 중에는 외부 자산을 요청하지 않습니다.

로컬 작업 결과는 `result_yyyyMMdd.html`에서 날짜별로 확인할 수 있어요. 결과 HTML, `prompt.md`, `AGENTS.md`, `docs/`는 내부 작업 기록으로 Git에서 제외해요.
